How to Use GitSync
Everything from getting a token to your first push
1
Get a GitHub Personal Access Token
One-time setup — takes about a minute
  1. 1Open github.com in a browser and sign in.
  2. 2Tap your profile photo in the top-right corner, then tap Settings.
  3. 3Scroll all the way down the left sidebar and tap Developer settings.
  4. 4Tap Personal access tokens → Tokens (classic).
  5. 5Tap Generate new token → Generate new token (classic).
  6. 6Give it a name like "GitSync" and pick an expiry.
  7. 7Under Select scopes, check the box for repo — this covers reading, writing and creating repositories.
  8. 8Scroll down and tap Generate token.
  9. 9Copy the token right away — GitHub only shows it to you once.
Using a "Fine-grained" token instead? Set Repository access to All repositories (not "Only select repositories") and give it Contents: Read and write permission. Otherwise a repository you create inside GitSync won't be covered by the token yet, and uploads to it will fail.
Open the step-by-step Setup guide
2
Connect Your Account
  1. 1Paste the token into the GitHub Personal Access Token field on the sign-in screen.
  2. 2Tap Connect to GitHub.

GitSync remembers this on your device, so you won't be asked to paste it again unless you disconnect. Add more accounts any time from Settings → Connected Accounts.

3
Pick a Repository & Branch
  1. 1Tap the Repository field, search or scroll, then tap one to select it.
  2. 2Tap the Branch field the same way to switch branches.
  3. 3Tap + Create new branch under the Branch field to make a new branch off the current one, right from the dashboard.
4
Push Your Code
  1. 1Pick Upload Project Folder, Upload ZIP File, or Upload / Change a Single File.
  2. 2Review what changed on the Compare screen — added, modified and deleted files are labeled clearly. Tap any file to preview its diff.
  3. 3Tap Review & Commit, write a commit message, then tap Commit Everything.

"Selected folder only" leaves files outside what you uploaded untouched. "Entire repository" mirrors the repo exactly, deleting anything not in your upload — use it with care.

5
Create a Brand-New Repository
  1. 1Open the Custom tab at the top of the app.
  2. 2Enter a repository name, choose Public or Private, and optionally attach a project ZIP to seed it with files right away.
  3. 3Tap Create Repository. If the initial upload ever fails, tap Retry Upload — the repository is already created, so this just tries the push again.
6
Everything Else
  1. •Open the Commits tab in the top bar to see App Commit (what GitSync last pushed) and Live GitHub Commit (the exact, real-time state of the branch). Tap Live GitHub Commit any time to fetch it fresh and see which files matched, which GitHub hasn't reflected yet, and which failed and need reuploading.
  2. •On the Commits page, tap View last 5 commits for full history — added, modified and deleted files, with +/- counts, for each of the last 5 commits.
  3. •In the Custom tab, tap Browse Files on any repository to view, edit or delete individual files.
  4. •Tap Publish on a public repository to host it live with GitHub Pages.
  5. •Switch between GitHub accounts any time from Settings → Connected Accounts.
