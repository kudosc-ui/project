TroubleshootingQuick fixes for common problems
"Invalid token" when connectingCopy the whole token again (it starts with ghp_) with no spaces, and make sure the repo box was ticked. "Permission denied" on a new repoIf you used a fine-grained token, set Repository access to All repositories and Contents to Read and write. A classic token with repo always works. Private repo has no Publish buttonCorrect — GitSync can't publish private repos. Open the repo on GitHub → Settings → Pages and publish it from there. My site link shows 404GitHub Pages needs 1–2 minutes to go live after publishing. Wait, then refresh.
